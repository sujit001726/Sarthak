  SARTHAK JOB PORTAL - SETUP CHECKLIST
═══════════════════════════════════════════════════════════════

Follow these steps IN ORDER:

□ STEP 1: DATABASE SETUP
  □ Start XAMPP Control Panel
  □ Click "Start" for MySQL (should turn green)
  □ Open browser → http://localhost/phpmyadmin
  □ Click "SQL" tab at the top
  □ Open file: SETUP_DATABASE.sql (in this project folder)
  □ Copy ENTIRE file content (Ctrl+A, Ctrl+C)
  □ Paste into phpMyAdmin SQL tab
  □ Click "Go" button
  □ Verify: Left sidebar shows "sarthak_db" with 12 tables

□ STEP 2: INTELLIJ SETUP
  □ Open IntelliJ IDEA
  □ File → Open → Select this project folder
  □ Wait for "Indexing..." to finish (bottom right)
  □ Wait for Maven to download dependencies (bottom right)
  □ Look for "Tomcat 11.0.18" in top-right dropdown
  □ If missing: Run → Edit Configurations → Add Tomcat Server

□ STEP 3: RUN THE PROJECT
  □ Click green "Run" button (or press Shift+F10)
  □ Wait for console to show "Tomcat started"
  □ Browser should auto-open to http://localhost:8089/

□ STEP 4: TEST LOGIN
  □ If not on login page, go to: http://localhost:8089/login.jsp
  □ Enter email: admin@gmail.com
  □ Enter password: admin123
  □ Click "Sign In"
  □ Should redirect to admin dashboard

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "Invalid Login" error?
   → Database not set up correctly
   → Go back to STEP 1 and run SETUP_DATABASE.sql again

❌ 404 Not Found error?
   → Tomcat not running or wrong port
   → Check IntelliJ bottom panel for Tomcat status
   → Verify URL is http://localhost:8089/ (not 8080)

❌ Database connection error?
   → XAMPP MySQL not running
   → Open XAMPP, click Start for MySQL
   → Check it's green in XAMPP control panel

❌ Build errors in IntelliJ?
   → Right-click pom.xml → Maven → Reload Project
   → File → Invalidate Caches → Invalidate and Restart

❌ Port 8089 already in use?
   → Edit Tomcat configuration
   → Change HTTP port to 8090 or 8091
   → Update URL accordingly
